# flightbroom

A free, open-source alternative to Adobe Lightroom® that can apply the Lightroom presets you already bought, faithfully.

**Status:** scoping. No code yet.

- [docs/SCOPE.md](docs/SCOPE.md): the project scope, strategy, roadmap, risks and open decisions. Start here.
- [docs/research/](docs/research/): deep-dive research on Lightroom's features, preset and profile formats, darktable, RawTherapee and the OSS ecosystem, processing algorithms, tech stack, and RapidRAW.
- [docs/adobe-docs/](docs/adobe-docs/): source-only digests of Adobe's official Lightroom and Camera Raw help.

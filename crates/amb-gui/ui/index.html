      Use

      Save as preset

      The photo's edit as it is now, as a one-click preset with an Amount slider. The crop, masks, retouching and geometry belong to this photo and are left out. It's a Lightroom-style .xmp file, so Lightroom can import it too.

      Paste settings

      Merge to HDR

      Deghosting takes moving things (people, leaves, water) from one exposure. The result is a DNG that edits like a raw, here and in Lightroom.

      Merge to Panorama

      Auto picks Perspective for up to about 100° (straight lines stay straight), Cylindrical for wide rows and Spherical for the widest or taller ones. Shoot with about a third of each frame shared with the next, turning the camera about the lens. The result is a DNG that edits like a raw, here and in Lightroom.

      Learn

      Lessons are a data file (lessons.json), so anyone can write or translate one.

      Surprise me

      Click a look to apply it. Each is an ordinary edit you can keep tweaking, and Undo takes it back.

      Assistant

      The key is kept in your system's keychain. The model gets numbers about the photo (brightness, clipping, colour cast) and its settings; it sees the photo itself only while "Show it the photo" is ticked. Your AI chat subscription can't be used here; with Claude Desktop or another MCP app, use amb mcp instead.

      Match look

      Measures how light, warm and colourful the references are, then finds the settings that give this photo the same. The photo shows the result before you apply it.
